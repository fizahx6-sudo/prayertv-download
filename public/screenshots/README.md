# Screenshots

Taruh file screenshot aplikasi di folder ini.

Nama file yang digunakan di web:
- `default-mode.png` — Tampilan utama (Default layout)
- `side-layout.png` — Side-bar layout dengan media player
- `top-layout.png` — Top layout (bar jadwal di atas)
- `media-player.png` — Media player (video/slideshow)
- `settings-menu.png` — Settings menu overlay

Format: PNG atau JPG
Resolusi yang disarankan: 1920x1080 (landscape/TV)
